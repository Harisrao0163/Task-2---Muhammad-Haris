📱 Responsive Web Layout

A fully responsive webpage built using HTML5 and CSS3, following a Mobile-First approach and modern responsive design principles to ensure seamless user experience across all screen sizes.

📖 Overview

Responsive Web Layout is a frontend development project completed during my Industrial Training at Decodelabs. The project focuses on creating a fluid and adaptable user interface that automatically adjusts to different devices, screen resolutions, and viewport sizes without compromising usability or accessibility.

✨ Features

- Mobile-First CSS Architecture
- Fully Responsive Layout
- CSS Media Queries for Multiple Breakpoints
- CSS Grid for Page Structure
- Flexbox for Component Alignment
- Fluid Units (% , rem , vw)
- Responsive Navigation Menu
- Hamburger / Popover Navigation (No JavaScript)
- Fluid Typography using clamp()
- WCAG-Compliant Touch Targets
- Cross-Device Compatibility
- Clean and Modern User Interface

🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

🧠 Development Approach

Input

- Project Requirements
- Responsive Design Principles
- Layout and Content Structure

Process

- Implemented a Mobile-First development strategy.
- Created responsive layouts using CSS Grid and Flexbox.
- Applied media queries for different screen sizes.
- Used fluid units to improve scalability.
- Developed an accessible navigation system without JavaScript.
- Implemented fluid typography using CSS clamp().

Output

- A responsive webpage that adapts across devices.
- Improved user experience on mobile, tablet, and desktop.
- Consistent layout, spacing, and readability across screen sizes.

📱 Responsive Breakpoints

The layout is optimized for:

- Mobile Devices (0px – 480px)
- Small Tablets (481px – 768px)
- Tablets & Laptops (769px – 1024px)
- Large Screens (1024px+)
